# Runtime Reference

This section describes interfaces visible to guest workloads and the host
network behavior that supports them.

- [Networking](networking.md): guest addressing, paths, link emulation, and
  multi-worker peering.
- [DNS](dns.md): names for satellites, ground stations, and the information
  service.
- [HTTP information API](http.md): machine, constellation, and path queries.
- [Time](time.md): guest clock behavior and Precision Time Protocol support.

Start with the [system architecture](../../handbook/05-system-architecture.md)
if the distinction between coordinator, worker, and guest microVM is new.
