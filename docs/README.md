# QUEST Documentation

## Handbook

The [`handbook`](handbook/01-project-overview.md) teaches the project from first
principles, then follows its source and runtime call flow. Beginners should
read the numbered chapters in order.

## Technical Reference

The [`reference`](reference/configuration.md) pages describe exact
configuration, build, runtime API, networking, output, and platform contracts.
Use them while changing code or diagnosing a run.

## Quickstart

The [quickstart](../quickstart/README.md) is the executable beginner path for a
local workstation and one administrator-provided, shared HPI remote VM.
